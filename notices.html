Signing and beta status

The Windows beta installer, uninstaller, two project-owned native executables and bundled command plugin use a self-signed beta certificate. This is a free consistency/integrity signature, not a certificate-authority-validated publisher identity. Windows does not automatically trust it. The public certificate is supplied for inspection; no trust-store import or operating-system security change is part of installation.

The Mac application, nested tools and installer use Apple Developer ID distribution identities, hardened runtime and trusted timestamps. Apple accepted the published package for notarization and its ticket is stapled. Notarization is not App Store approval, endorsement or commercial clearance.

The primary Quest app is the production-signed, non-debuggable ARM64 build 0.2.0-beta.1, distributed through an age-restricted private Meta release channel for Quest 3/3S. Meta channel membership shares the tester’s Meta email address and alias with AldoApps and permits release-channel email. The app has not been submitted for public Meta Horizon Store review. The GitHub release retains a differently development-signed, debuggable direct APK only as a technical fallback; Android cannot update between the two signing identities without an intentional uninstall that can erase app-local settings. A signed file is not a guarantee of safety, compatibility or certification.

Local app processing

The Mac and Windows Companions capture selected simulator instrument windows. Outside view, X-Plane process audio and ISCS sharing are separate controls. Audio does not capture the microphone or the general desktop mix. ISCS touches use the explicitly selected, foreground, uncovered simulator window. Local control requests are bounded and require a fresh armed session.

USB forwarding carries loopback media/control services to Quest. Simulator UDP and local HTTP are not encrypted pairing protocols. Do not expose these ports to the internet or use them as a remote-access service. The beta has no added analytics, advertising, automatic diagnostic uploader or account requirement. Local settings and logs remain on your computer; support sharing is your choice.
